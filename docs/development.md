# Development Notes

## Conventions

- Use Python 3.11+
- Keep new modules inside `src/orbit_core/`
- Add tests for every behavior change
- Document public-facing behavior in `README.md` or `docs/`

## Release Rhythm

This package is intended to be the first Orbit sprint artifact:

- Build the smallest useful foundation
- Capture decisions in docs
- Keep the archive ready for clean extraction into the main workspace
